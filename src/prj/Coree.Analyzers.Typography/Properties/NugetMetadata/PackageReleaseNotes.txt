2026-10-26

 - A u8 string literal uses the same quote escaping as the string it suffixes. "..."u8 writes a double quote as \", and @"..."u8 writes it as "". A raw string with a u8 suffix is not edited, and the warning still reports.

2026-10-25

 - In a C# document, the editor can replace a flagged character with the ASCII character that warning already names. An en dash, em dash, or minus sign becomes a hyphen. A curly double quote or guillemet becomes a straight double quote, escaped so a string literal still parses. A single quotation mark or typographic apostrophe becomes an apostrophe. An ellipsis becomes three periods. A no-break space becomes a normal space. A raw string is not edited. The fix runs only when you apply it.
 - CTYQM001 flags the opening single quotation mark (U+2018), the single low-9 quotation mark (U+201A), and the single high-reversed-9 quotation mark (U+201B), in addition to the curly double quotes and guillemets it already flags.
 - The closing single quotation mark (U+2019) stays on CTYAP001 only.
 - Fix Typography Excludes so each pattern is its own glob. The default extension list, including an empty Excludes value, no longer registers those files as additional files.

1.0.2 (2026-10-08)

 - A file already in Compile stays on the C# syntax tree and is not registered again as an AdditionalFile.
 - A .cs file that is not compiled is still an additional file when the globs match.

 - Initial release.

 - CTYEL001 flags horizontal ellipsis (U+2026).

 - CTYNB001 flags no-break space (U+00A0) and narrow no-break space (U+202F).
