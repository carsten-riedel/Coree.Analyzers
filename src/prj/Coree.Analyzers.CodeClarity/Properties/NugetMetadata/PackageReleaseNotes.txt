2026-10-25

 - Package versions use the build number (1.0.N).
 - CCCRC001 scores a yield return expression the same way it scores a return expression. yield return a + b + c reports at the default maximum. yield return a + b stays quiet.
 - Fix CCCMB001 false positives for blank lines in files with CR-only, Unicode, or mixed C# line endings. LF and CRLF behavior is preserved.
 - Fix CCCRC001 undercounting calls to user-defined methods named nameof or @nameof. The C# nameof operator remains exempt.
 - CCCRC001 counts a user-defined operator + even when one operand is a string. Built-in string concatenation still does not count.
 - CCCRC001 counts unsigned right shifts (`>>>`) as one calculation step, consistently with `<<` and `>>`. A lone shift remains allowed at the default maximum.
 - CCCPL001 puts the closing parenthesis on the line after the last parameter ends. An attribute or a default may span lines. A closing parenthesis on that parameter's last line reports.
 - CCCPL001 reports two parameters that share a line even when the earlier parameter began on a previous line. A wrapped parameter that ends before the next parameter starts stays quiet.
 - CCCPL002 stays quiet when a parameter list contains a line comment, so it does not recommend a one-line spelling that would comment out the rest of the signature. A // inside a string can still report.
 - CCCPL002 stays quiet when a parameter list contains a preprocessor directive, so it does not recommend a one-line spelling that cannot keep #if, #region, or the other directives. A #if sequence inside a string can still report.
 - CCCPL002 stays quiet when a parameter literal contains a line break (CR, LF, CRLF, U+0085, U+2028, or U+2029), so it does not recommend a one-line spelling that would change a verbatim, raw, or interpolated string. An escaped \n in a regular string can still report.
 - CCCPL002 keeps whitespace inside literals when measuring a wrapped parameter list. Formatting whitespace outside tokens still collapses.

0.1.5 (2026-10-08)

 - CCCPL001 flags a parameter list that spans more than one line while one of those lines still starts more than one parameter.
 - Methods, local functions, constructors, and primary constructors of classes, structs, and records are in scope.
 - Default severity is warning. Set ParameterListLayoutAnalyzerSeverity to warning, error, message, or off.

0.1 (2026-10-07)

 - Initial release.
 - CCCRC001 flags a return expression whose calculation-step score exceeds ReturnTypeComplexityAnalyzerMaximum (default 1).
 - String concatenation and nameof do not count. One arithmetic operator, one method call, or one conditional is allowed at the default.
 - Default severity is warning; set warning, error, message, or off.
